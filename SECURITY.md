# Security and privacy

Please do not include any of the following in an issue, pull request, or public repository:

- Browser cookies or `Cookies.txt` files
- API keys, access tokens, passwords, or account data
- Application settings files that contain local paths
- Downloaded media, subtitles, OCR output, transcripts, or logs containing private URLs

ACAN Studio can use browser cookies only when the user explicitly enables that option in Settings. Keep the default disabled when testing changes that do not require authenticated downloads.

If you find a security issue that could expose credentials or private data, avoid posting the details publicly until the issue has been assessed and mitigated.
